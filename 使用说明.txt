极简解压工具 - 使用说明
=================================

1. 环境准备
   - 确保已安装 Python 3.7 或更高版本
   - 运行: pip install -r requirements.txt

2. 打包成EXE
   - 在Windows系统上运行: build.bat
   - 或手动执行: pyinstaller --onefile --windowed --name="极简解压工具" extract_tool.py

3. 使用方法
   - 打包完成后，在 dist 目录中找到 "极简解压工具.exe"
   - 双击运行，选择压缩文件和解压位置即可

4. 支持格式
   - ZIP (*.zip)
   - TAR (*.tar, *.tar.gz, *.tar.bz2, *.tgz)

特性：
- 免安装，单个EXE文件即可运行
- 界面极简，操作简单
- 完全免费
